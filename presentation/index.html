OverFlowEngine
Feature · Models

Bring your own model.

  • Paste an OpenAI, Anthropic or Google key. It recognises the provider.
  • Unlock one AI Model block and pick the model.
  • Wire it into as many blocks as you like.

Your key. Your model. Any block.

OverFlowEngine
Feature · Agents

One form in. A whole trip out.

  • One agent picks the place, another writes the itinerary.
  • Real Google + Apple Maps routes for the stops.
  • Trip Cost searches the web for prices, then a Trip PDF comes out.

Demo data in the video is illustrative.

OverFlowEngine
Feature · Apps

Your flow can talk in Discord.

  • Link your own bot once.
  • Drop an App Action block in a flow: pick the bot, channel and message.
  • It posts, waits for the first reply, and answers it with AI.

Google and Microsoft Calendar actions sit alongside it. Bot, token and chat in the video are stand-ins.

OverFlowEngine
Feature · Marketplace

Share a flow. Copy anyone's.

  • Publish a saved flow in one click.
  • Anyone can copy it into their own account.
  • AI Model blocks are never shared. Copiers link their own key.

Usernames and listings in the video are illustrative.

Under the hood

Built to grow into an agentic platform.

CANVAS

React Flow

A React canvas with grid snapping and node-to-node alignment guides.

ENGINE

FastAPI

Runs flows server-side: variables, branching, logging, persistence.

DATA

Postgres + Redis

Started through Docker by the project's start script. Runs are recorded.

APPS

MCP + keys

Discord through an MCP server, and models run on keys you bring.
