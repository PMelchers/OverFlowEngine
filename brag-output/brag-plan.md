# Brag Plan: OverFlowEngine (restored)

**What:** A drag-and-drop workflow builder (n8n / Zapier / ComfyUI energy): wire blocks on a canvas, hit Run, and a server executes the graph, with AI Agent blocks as first-class citizens.
**Angle:** "Wire it. Run it. Let an agent decide." The real Email Auto-Reply template (Email Trigger → Extract Instructions → Draft Reply → Send Reply) gets built, run with the app's green node-flash, and an agent drafts a reply. Dry joke: the blocks collapse into a group called "my whole job".
**Tone:** default. 20s, 1920x1080. Music: happy-beats vol-1 (trimmed from 2.52s so beats land on 0.5s multiples).

## Storyboard
1. **Hook (0–3s):** a Trigger block drops onto a blank grid. "Automation, but you draw it."
2. **Build (3–8.5s):** the palette (Core Blocks / Agentic Blocks) slides in; blocks drop one by one; wires draw; an alignment guide flashes. "Drag. Snap. Wire."
3. **Run (8.5–14.5s):** click Run; the green pulse travels node to node; the Console logs each step. "Run it. Server-side."
4. **Agent (14.5–17.5s):** zoom on Draft Reply as it types a reply. "Blocks that think."
5. **Punchline (17.5–20s):** the blocks collapse into the group "my whole job"; OverFlowEngine: "Draw the workflow. Run the workflow."
